The README names these entry points:

- `Play.java` (sources root): runs games. Player types are set in `_getAgent` and the `PlayerType` enum.
- `Tournament.java`: runs round-robin tournaments, configured by `tournament.json`.
- `core/Constants.java`: the `VISUALS` flag toggles visuals.
- `core/TribesConfig.java`: game configuration, such as unit attack power.

## README summary

The project is an open source AI research framework for *The Battle of Polytopia*. The README describes it as a multi-player, multi-agent, stochastic, partially observable turn-based strategy game. It requires Java 8 or later and provides a Forward Model for statistical forward planning methods. It cites a 2020 AIIDE paper by Pérez-Liébana et al.
